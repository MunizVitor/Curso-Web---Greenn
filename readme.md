# 🌱 Greenn School – README

## 📘 Sobre a Greenn
A **Greenn** é uma empresa referência em soluções digitais para negócios online.  
Ela oferece ferramentas de checkout, área de membros e automação de marketing, ajudando produtores e afiliados a aumentarem suas vendas e conversões.  
Além disso, promove iniciativas educacionais como o **Greenn School**, capacitando profissionais em tecnologia e programação.

---

## 🎓 O Programa – Greenn School
Estou participando do **Greenn School de Programação Web**, um curso oferecido algumas vezes por ano pela empresa.  
O programa é voltado para formar desenvolvedores e ampliar conhecimentos em tecnologias modernas de desenvolvimento web.
